# Frontend

Placeholder Next.js + TypeScript app. Replace with real work once the team agrees on the design and
stack details (styling approach, state/data-fetching libraries, etc. are all open).

## Setup

```bash
cd frontend
npm install
cp .env.example .env.local
```

## Run

```bash
npm run dev
```

## Checks (same ones CI and pre-commit run)

```bash
npm run lint
npm run format:check
npm run typecheck
npm test
npm run build
```
